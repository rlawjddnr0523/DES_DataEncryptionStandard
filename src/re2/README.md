# <ins>Data Encryption Standard Encryption Algorithm</ins>(JAVA)

### The Functions need in this algorithm
1. Permute
   1. Initial Permutation **(IP)**
   2. Final Permutation **(FP)**
2. F function **(F)**
3. Key Generation Function **(K)**
4. Trans Type Function (ex: BinToHex, HexToBin)
5. ETC...

* * * 
### Input Types
* Plaintext(PT) : Hex(16) Inputs (ASCII maybe apply (not yet))
* KEY(KEY) : ASCII 8bit Input **(ONLY ENGLISH and Numbers)**
